[2.11] Training attempt 1 -- FAILED in 0.16 min
  ERR: pycolmap/scene_manager.py:102
       num_cameras = struct.unpack('L', f.read(8))[0]
       struct.error: unpack requires a buffer of 4 bytes

  *** ROOT CAUSE #3 (confirmed) ***
    Python's struct format 'L' WITHOUT a byte-order prefix uses NATIVE size.
      Linux   (LP64):  unsigned long = 8 bytes  -> works
      Windows (LLP64): unsigned long = 4 bytes  -> reads 8, unpacks 4 -> error
    The rmbrualla/pycolmap fork is silently Linux-only. COLMAP's binary format
    actually stores these as uint64, so the correct format is '<Q'.
    Same class of bug at 'IiLL' (line 105): COLMAP writes camera width/height
    as uint64, so the correct format is '<IiQQ' (4+4+8+8 = 24 bytes, matching
    the f.read(24) already in the code).
